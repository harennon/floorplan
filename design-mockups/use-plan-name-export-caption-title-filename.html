Export caption title & filename

LLD 158 · uses plan name from LLD 157

Once a plan has a name (LLD 157), the exported PNG/SVG should say what it is and save under a recognizable filename. This swaps the fixed "Floor plan" literal in the caption band (LLD 153) for the plan name, and derives the download filename from a slugified name. Everything below is rendered at the same layout the real export path produces — the caption band is a top strip, geometry sits below it, scale bar at the bottom.

The caption band swaps the "Floor plan" literal for the plan name; the right-hand area · perimeter metrics are unchanged (LLD 153). When the name is empty/absent the title falls back to "Floor plan" so the band never renders blank. When there is no enclosed area the whole caption band is omitted (band height 0) — but the filename still derives from the name, since a name-only plan is still recognizably "my-studio".

2 · Long name in the caption — collision handling

Title is left-anchored, metrics right-anchored (LLD 153). A 60-char name on a narrow plan can run into the metrics. LLD 153 Edge Case 5 explicitly accepts overlap for v1, but since the name is now user-controlled it is worth choosing. Two options:

Option A — truncate title (ellipsis)recommended

Title is clipped to a max width (metrics width reserved) and an ellipsis is appended in SVG. Metrics always readable; no overlap. Costs a text-measurement pass (measure the metrics string, budget the remaining width for the title).

Option B — accept overlap (v1 status quo)simplest

Exactly what LLD 153 does today: both anchored, no measurement, they can overlap on a narrow export. Zero added code. The name is capped at 60 chars, so worst case is bounded, and most plans are named short ("Studio", "Apt 3B"). Only ugly on genuinely narrow plans with genuinely long names.

3 · Filename slug rules (live)

Type a plan name to see the derived download filename. Rules: lowercase, spaces → hyphens, strip anything that isn't a–z 0–9 -, collapse repeated hyphens, trim leading/trailing hyphens. If the result is empty (emoji-only, symbols-only, whitespace-only), fall back to floorplan.
