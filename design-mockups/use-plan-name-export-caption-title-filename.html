Plan name as export caption & filename

The exported PNG/SVG is the artifact people actually send. Today the caption title is the fixed literal “Floor plan” and the file always saves as floorplan.png. Once a plan has a name (LLD 157), the caption should say what it is and the file should save under a recognizable, slugified name.
